02 — Objectives

What the project set out to do

General objective

Design and implement a standalone, containerized HIDS that uses an unsupervised autoencoder to detect hidden threats in encrypted network traffic through flow-based behavioral analysis.

1
Feature extraction
Design a less intrusive procedure that captures session metadata and timing features without decrypting packet payloads.
2
Model training
Train and optimize an autoencoder that models the traffic baseline and flags anomalies through reconstruction error.
3
Backend & deployment
Deploy the detection engine with FastAPI and Docker, with an integrated SQLite database for forensic logging.
4
Dashboard
Build a high-performance PySide6 interface for live threat monitoring, alert visualization and analyst feedback.

03 — Problem · Literature · Gap

Why existing IDS tools fall short on encrypted traffic

The problem: over 95% of web traffic is now encrypted, so signature-based deep packet inspection cannot read payloads, and decrypting them raises privacy, legal and performance concerns.

Research gap: no lightweight, open, privacy-preserving host-level tool detects novel threats in encrypted traffic from behavioral metadata alone. This project fills it.
