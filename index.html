02 — Objectives

What we set out to do

General objective

Build a standalone, containerized HIDS that uses an unsupervised autoencoder to detect hidden threats in encrypted traffic from flow behavior.

1
Feature extraction
Capture session and timing metadata without decrypting payloads.
2
Model training
Train an autoencoder on normal traffic and flag anomalies by reconstruction error.
3
Backend & deployment
Serve detection with FastAPI and Docker, logging forensics to SQLite.
4
Dashboard
A PySide6 console for live monitoring, alerts and analyst feedback.

03 — Problem · Literature · Gap

Why current IDS tools struggle with encryption

Problem: over 95% of web traffic is encrypted, so payload-based inspection is blind to it.
Tool typeLimitationAE-HIDS answer
Signature · Snort, SuricataMisses zero-days; needs decryptionLearns normal behavior, no signatures
Anomaly · ZeekManual scripts; heavy on resourcesDeep-learning baseline replaces scripting
Host · OSSECBlind to encrypted flowsReads host flow metadata directly
Hybrid · Cisco FirepowerCostly, vendor lock-inOpen, lightweight Python stack
Gap: no open, lightweight, privacy-preserving host tool detects novel threats in encrypted traffic from behavior alone.

05 — Autoencoder

How the autoencoder detects anomalies

1 · Learn normal
Trained on benign flows only. It never sees an attack.
2 · Reconstruct
22 inputs squeezed to 4, then rebuilt. Unusual flows rebuild badly.
3 · Alert
Error (MSE) above τ = 0.5 raises an alert.
# ReLU dense layers · Adam · MSE loss · batch 512 · early stopping
scaler.pkl → baseline_ae.keras → MSE(x, x̂) → compare with τ in threshold.yaml

06 — Data Pipeline

From raw packets to alerts

1
Capture
Scapy sniffs the interface and groups flows by 5-tuple.
2
Extract
22 behavioral statistics per flow.
3
Scale
Saved scaler matches the training data.
4
Infer
Autoencoder rebuilds the flow; MSE is the score.
5
Alert
If MSE > τ, log to SQLite and update the console live.
Privacy by design: only Layer 3 and 4 headers are used. Payloads are never read or decrypted.

09 — Training & Evaluation

Training results

Training
  • 100 epochs, 387 s, CPU only
  • No over-fitting seen
At τ = 0.5
  • ROC-AUC 0.957
  • False alarms: 923 of 98,345 (0.94%)
  • Caught 34,559 attacks, missed 173,979

12 — Findings

Performance, limits and next steps

0.957ROC-AUC
0.974Precision
0.94%False alarms
0.166Recall
0.661 msPer flow
1,965/sThroughput
What worked
  • Full pipeline, live console
  • Beats Isolation Forest (0.957 vs 0.788 AUC)
  • CPU-only laptop, 3.1% CPU
Limits
  • Low recall at τ
  • Encrypted-port attacks untested
  • Single host, no live drift test
Next
  • Lower τ, per-attack recall
  • Drift detection, retraining
  • Multi-node, explainable AI
